# 技法辞典：トレンドのルック（44種）

索引は [index.md](index.md)。ここの名前は、SNSや画像・動画生成サービスで広まった呼び名。**Seedance が名前そのものを理解する保証はないので、名前をプロンプトに書かず、記述例のように光・色・質感・動きの要素へ分解して書く。** ユーザーが「〇〇風」と名前で頼んだときに、中身を引くための表として使う。

- ありえない状況（動物に乗る、普段着で怪物と戦う）は、ふざけた演出にせず普通の撮影のように真面目に撮ると成立しやすい。
- 絵画や名画を思わせるルックは、特定の作品の複製ではなく、光・色・筆致の特徴で書く。
- 雑誌の見出しなど画面の文字は崩れやすいので入れない。必要なら後編集を提案する。

表の見方：「技法」は呼び名、「記述例」はプロンプトに書く型。被写体・場所は依頼に合わせて書き換え、例をそのまま貼らない。
