# 技法辞典：大気と天候（13種）

索引は [index.md](index.md)。雨・霧・煙・埃は、横や後ろからの光と組み合わせると形が見える（[lighting.md](lighting.md) の Backlight・Volumetric Light）。天候は「環境」の項目に書き、光の向きと一緒に指定する。

表の見方：「技法」は英語の呼び名、「記述例」はプロンプトに書く型。被写体・場所は依頼に合わせて書き換え、例をそのまま貼らない。

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Rain | 雨 | 逆光や横からの光で雨粒を光らせ、暗い背景で筋を見せる。地面も濡らす | `Heavy rain。逆光の街灯に雨粒が白い筋として光り、濡れた路面に光が映る。` |
| Fog | 霧 | 濃い霧で距離とともにコントラストが落ちる。灯りの周りに光の輪 | `Dense fog。数メートル先の人影が灰色に溶け、街灯の周りにぼんやりした光の輪ができる。` |
| Mist | もや／靄 | 霧より薄く、次の層がまだ見える。朝や山の静けさ | `Thin morning mist。湖面の上を薄いもやが低く漂い、対岸の森がうっすら見える。` |
| Atmospheric Haze | 大気のかすみ／空気遠近 | 遠くの層ほど明るく、コントラストが落ち、空の色に近づく | `Atmospheric haze。重なる山並みが奥へ行くほど淡く青くかすむ。` |
| Smoke | 煙 | 方向を持って漂う煙。横や背後から照らすと形が見える | `Drifting smoke。線香の煙が横からの光に照らされ、ゆっくり渦を巻いて天井へ昇る。` |
| Dust Motes | 光の中の埃 | 光の筋の中にだけ見える、ゆっくり漂う細かい粒 | `Dust motes floating in a beam of light。窓から差し込む光の筋の中で、細かな埃がゆっくり漂う。` |
| Steam | 湯気／蒸気 | 発生源（やかん・マンホール・シャワー）から立ち上り、風で流れる。煙より白く湿った感じ | `Rising steam。夜のマンホールから白い蒸気が立ち上り、背後のネオンに照らされて流れる。` |
| Snow | 雪 | 逆光や横からの光で雪片を浮かせ、髪や服に積もらせる | `Falling snow。大きな雪片が逆光に光りながら舞い、人物のコートの肩に積もっていく。` |
| Wet-Down | 濡れた路面／ウェットダウン | 雨は降らせず路面だけを濡らし、夜の灯りを反射させる | `Wet street, no rain falling。雨上がりの濡れたアスファルトに、ネオンと信号の光が長く映り込む。` |
| Sparks and Embers | 火の粉・火花 | 溶接・焚き火・金属の研削から飛ぶ橙色の光の粒。粒そのものが光る | `Sparks and embers。溶接の火花が暗い工場に橙色の弧を描いて飛び散り、作業員の面を照らす。` |
| Dust and Sand | 砂塵・砂嵐 | 風に運ばれた砂で太陽が鈍い円盤になり、人物がシルエットになる | `Dust storm。砂嵐で太陽が鈍い白い円盤になり、歩く人物が茶色い空気の中でシルエットになる。` |
| Underwater | 水中 | 揺れる光の網目模様（コースティクス）、気泡、浮遊感。水平線がない | `Underwater shot。水面から差す光が揺れる網目模様を作り、ゆっくり浮かぶ人物の周りを細かな気泡が昇る。` |
| Ocean | 海 | うねり、水平線、潮風のかすみ。海そのものがもう1人の登場人物になる | `Open ocean。灰色のうねりが続く海と水平線、甲板に立つ人物に波しぶきがかかる。` |
