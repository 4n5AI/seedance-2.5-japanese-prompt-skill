# 複数ショットの連続性ガイド

1回の生成で複数のショットを出すとき、また延長・分割で映像をつなぐときの連続性の作り方。時間指定の書式は [prompt-syntax.md](prompt-syntax.md)、ショットサイズは [shot-composition.md](shot-composition.md)、カメラの動きは [camera-movements.md](camera-movements.md) を参照する。

---

## 1. 前提：モデルは「カメラ」を記憶しない

動画生成AIには、生成をまたいで持続するカメラの状態が存在しない。各生成はプロンプトと参照素材から作られる新しいリクエストで、**前のショットで人物が画面左に立っていたことをモデルは知らない**。指示を省くと、モデルはそのショット単体で最も見栄えのする構図に落ちる。

同様に、モデルは**イマジナリーライン（180度ルール）の概念を持たない**。ルール名を書いても効かない。効くのは具体的な配置の記述だけ。

- 効かない：`follow the 180 degree rule`
- 効く：`A stands on the left of frame facing right, B on the right facing left` を**両方のショットに同じ文で置く**

この性質は第三者の検証報告に基づくもので、Seedance 2.5 での検証ではない。ただし「配置を明記する」対処は害がなく、書いておいて損はない。

---

## 2. 実装の4原則

1. **シーケンス単位ではなくショット単位で書く。** 長い尺を一息の描写で狙うと、冒頭だけ意図どおりで残りがずれていく。区間ごとに独立して読める記述にする。
2. **維持要素を各ショットで反復する。** 人物の外見・服装・画面上の立ち位置（左右）・光源の方向・色調は、変える必要がないなら毎ショット同じ文で繰り返す。**変えるのは変えるべき要素だけ。**
3. **隣接ショットはサイズを必ず変える。** ロング／ミディアム／アップは単独では場面として成立しない。画角の変化がリズムと物語を生む。同じサイズが連続すると、つながっていない「同じ絵の飛び」に見える。
4. **カメラ位置も動かす。** 次のカットが前のカットと近い角度だと、同じカットで時間が飛んだように見える（30度ルールの発想）。ショットごとに `front` / `three-quarter` / `profile` / `low angle` などを書き分ける。

## 3. 編集文法の語彙と、プロンプトでの書き換え

| 用語 | 英語 | 意味 | プロンプトでどう書くか |
|---|---|---|---|
| イマジナリーライン／想定線 | imaginary line / 180-degree rule | 2人を結ぶ想像上の線。カメラは同じ側に留まる | 「誰が画面のどちら側で、どちらを向くか」を全ショットに明記する |
| 30度ルール | 30-degree rule | 次のカットはカメラ位置を30度以上変える | ショットごとにアングルを書き分ける |
| アクションつなぎ | cutting on action / action match | 一連の動作の途中でカットを切り替える | ショット1は動作の開始、ショット2はその続きの瞬間から、と動作のフェーズで書き分ける |
| 視線つなぎ | eyeline match | 視線方向を意識して次のカットへつなぐ | 「Aは画面左を見る → 次のカットは対象を右から左向きに捉える」と方向を明記する |
| マッチカット | match cut | 似た形・動きでシーンをつなぐ | 両ショットで形状・構図・動きを**同一の言葉**で記述する |
| ジャンプカット | jump cut | 時間・空間を飛ばし、不連続を見せる | 意図的に使うときだけ明示する。既定では起きないよう `one-take shot` / `no jump cuts` で制約する |
| クレショフ効果 | Kuleshov effect | 観客は人物が見ているものから、その人物の感情を読み取る | 中立的な表情を明記し、対象のカットと並べる |
| カットのリズム | pacing | 長いカットは落ち着き、短いカットはスピード感 | 1ショット3〜7秒を基準に秒数を割り付ける。ただし区間数の上限（30秒で4〜6本）と両立させると1区間は5〜7秒程度になるため、長尺では下限側（3〜4秒）を並べない |
| 上手／下手 | screen right / screen left | モニター上の右が上手、左が下手 | 日本語の呼称は通じない。`screen left` / `screen right` に必ず翻訳する |

## 4. 維持要素のチェックリスト

複数ショットを書いたら、各ショットに次が明記されているか確認する。変わってよいものと、変わってはいけないものを分ける。

| 項目 | 変えない（全ショットで反復） | 変える（ショットごとに書き分け） |
|---|---|---|
| 人物 | 年齢・髪型・服・体格などの識別特徴 | 表情、姿勢、動作 |
| 配置 | 画面上の左右関係、向き | 被写体との距離 |
| 光 | 光源の方向、色温度、時間帯 | 当たり方の強弱 |
| 色 | 色調・グレード | — |
| カメラ | — | ショットサイズ、アングル、動き |

参照素材を使う場合の役割束縛と、再登場点でのアイデンティティ再宣言は [prompt-syntax.md](prompt-syntax.md) の該当節に従う。

## 5. 絵コンテからプロンプトへの写像

絵コンテの1コマが記録する項目は、そのままプロンプトの各項目に対応する。ユーザーが絵コンテを持っている場合は、この対応で読み替える。

| 絵コンテの欄 | プロンプトの記述先 |
|---|---|
| 絵（ショットサイズ・アングル・構図） | カメラの距離と角度。`Medium close-up, eye level` に日本語で対象を補う |
| 矢印（カメラの動きの方向） | カメラの移動。`Slow dolly in` など（[camera-movements.md](camera-movements.md)） |
| 秒数 | 時間区間の見出し。`0〜3秒:` など（[prompt-syntax.md](prompt-syntax.md)） |
| セリフ | 発話。話者を明示し、リップシンクの3規則を適用する |
| 音（効果音・BGM） | 音声。効果音は動作に結び付ける |
| コマの並び | ショットごとに独立して記述し、維持要素を各ショットで反復する |

絵コンテのコマ順と時間区間を対応させる。コマを飛ばしたり、1コマに複数のカメラ動作を詰め込んだりしない。

## 6. 長尺・分割・延長との関係

- 対象サービスで長尺モードが使えるなら一括生成を検討する。長いだけで必ず分割生成にしない。
- 分割する場合は、各パートの冒頭で維持要素（人物・光・色調・画面上の配置）を再宣言する。パート間の境界では、前のパートの終端状態から続くように書く。
- 延長の書き方と、資料上の尺の条件は [source-guide.md](source-guide.md) の該当節を参照する（**公式資料で確認済みの条件**）。

---

## 7. 注意事項

- 本ファイルの編集文法（180度ルール、30度ルール、マッチカット等）は一般的な映像制作の知識であり、**Seedance の公式資料には含まれない**。
- 「モデルはカメラを記憶しない」「ルール名を書いても効かない」という記述は第三者の検証報告に基づき、その多くは他モデルでの検証である。**Seedance 2.5 での検証ではない**ので、ユーザーへ断定して伝えない。
- 1ショット3〜7秒という基準は編集の一般的な目安。Seedance 2.5 の時間区間の制約（整数秒、隙間なし、1区間3秒以上、30秒なら4〜6本）は [prompt-syntax.md](prompt-syntax.md) を優先する。
